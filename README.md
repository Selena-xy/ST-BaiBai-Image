# 柏宝绘 · SillyTavern 剧情配图助手

> 让 AI 的每一段精彩剧情都有画面。柏宝绘会一边陪你聊，一边默默判断「这一幕值不值得画」，自动挑选最值得定格的瞬间、写好生图提示词，再交给出图渠道生成图片，直接嵌进楼层里。全程自动，也可随时手动接管。

光有文字的故事总觉得少了点什么——角色长什么样、战斗场面有多燃、告白那一刻的光线，都只能靠脑补。柏宝绘就是为了把「脑补」变成「亲眼看到」而生的：它不打扰你聊天，只在恰到好处的时候递上一张图。

## 本版改了什么（相对上游 v0.3.2）

本仓库是上游 [baibai-git/ST-BaiBai-Image](https://github.com/baibai-git/ST-BaiBai-Image) v0.3.2 的改版分支，只做加法：**给 NovelAI 出口加了 Anima 与自然语言两套单串提示词风格**，另修了几处角色档案的口径问题。ComfyUI 侧与上游一致。

### 📝 NAI 新增「自然语言单串」提示词风格

在「Anima 提示词风格」的基础上再加一档：NAI 渠道「默认参数」的「提示词风格」下拉现在是三选一，新档**只出自然语言**——

- **NAI 原生（Base + Character Prompts）**：上游行为。
- **Anima 单串（自然语言为主）**：单串 danbooru tag + 可选自然语言。
- **自然语言单串（纯描述，无 tag）**：提示词是一整段连贯英文画面描述，**不写任何 danbooru tag**。请求协议不变（仍是 NAI 的 generate-image），只是整条正向提示词换成了纯描述。

具体口径：

- **散文装在原有 tag 键里**：输出协议的 JSON 形状不变（position / tag / size 三键），`tag` 键里装的是 2~6 句、约 80~140 词的英文描述；不写 `nl` 键、不产 `characters` 与 `char_captions`、不产 `negative`。正文、卡片、编辑弹窗、图库、promptHash 全链路零改动，历史楼层不受影响。
- **首词是安全档**：描述第一个词必须是 `safe` / `sensitive` / `nsfw` / `explicit` 四档之一（后接句点），四档判据与 Anima 相同——这条链路只写正面，档位是唯一的内容分级手段。
- **角色归属靠行文**：每个入画的人用自己的区分性称谓点出（the girl with long black hair），外貌、服装、动作贴着称谓写；跨人接触写清「谁的手、放在谁身上」。库中角色的固定外貌字段值**原样织入**句子，不换词。
- **正面前缀完全交给你**：与 Anima 一致，插件不注入任何内置质量词；你填的「正面质量词」/画师串会被提到描述**最前**，两处都留空就是纯描述直发。
- **尺寸吸附同样可用**：「尺寸吸附到网关三档」对单串风格（Anima / 自然语言）都生效，给按网关特性出图的兼容站用。
- **「生成自然语言」开关在此风格下隐藏**：整段描述就是自然语言，开关没有意义；切回其它风格后照常生效。
- 设置页「提示词」区多出两套可编辑的：**自然语言规范**与**自然语言思维链**（建档、服装视觉指纹、表情视线朝向、画面补全等纪律完整继承，写法全部换成散文口径）。

### 🎴 NAI「Anima 提示词风格」

NAI 渠道面板的「默认参数」里的「提示词风格」下拉，另有 Anima 一档：

- **NAI 原生（Base + Character Prompts）**：改动前的行为，一个字都没动。
- **Anima 单串（自然语言为主）**：这条 NAI 出口从此只出 Anima 口径的提示词 —— 单串输出（没有 Base 与角色槽位之分）、自然语言为主体、角色外貌全部写进主体、不产出 `characters` / `char_captions`、不发 NAI 官方质量词、不写 `::` 权重与反斜杠转义括号。**请求协议完全不变**，还是 NAI 的 `generate-image`，只是提示词换了个写法。

配套的两件事：

- **尺寸吸附到网关三档**：竖 920×1536 / 方 1024×1024 / 横 1536×920，按宽高比就近取档（1536×1152 会被判成方图）。给按 Anima 特性出图的 NAI 兼容站用；关掉则原样下发。
- **正面前缀完全交给你**：Anima 下插件不注入任何内置质量词 / 年代词。「正面质量词」两处（画师串绑定值 → 渠道级）都留空就是不追加；填了会被提到整个 tag 串**最前**（Anima 的 section 顺序要求质量 / 年代词打头，与 NAI 的「拼在画面 tag 之后」相反，面板说明会跟着风格自动切）。

设置页「提示词」区也多出两套可编辑的：**Anima 规范** 与 **Anima 思维链**，与 NAI 那两套并列，同样支持 `{{#nl}}…{{/nl}}` / `{{^nl}}…{{/nl}}` 条件段。

### 📝 Anima 规范与思维链：按官方口径重写

这两份就是 AI 写提示词前读的东西 —— **规范**管「怎么写」，**思维链**管「写之前怎么想」。底稿是插件原有的 NAI 4.5 / V5 那两份（输出契约、姓名一致性、画面补全、画幅方向、示例结构整套照搬），换掉的是出口形态与写法依据，依据来自 Anima / Anima-2.9B 的模型卡。两份都是内置默认，设置页里可以全文改写。

**规范**换掉的几条：

- **结构：双结构 → 单串。** NAI 那份是「Base + 每个角色一块」，这份是「一张图一条 tag 串」—— 角色外貌、服装、动作、场景全在一条串里，没有 Base 与角色槽位之分。
- **角色归属：块隔离 → 邻接绑定。** 单串没有槽位可以隔离每个人，所以「谁穿什么、谁在做什么」必须贴着那个人写：段首用发型 + 方位作锚点（`long black hair girl on left`），跨人容易混淆的属性用 `X on Y` 绑过去（`white dress on long black hair girl`）。规范里给了 ✔ / ✘ 对照 —— 写成 `white dress, grey uniform, girl A, girl B` 那种把衣服和人拆散的写法，模型会随机分配，同框两人经常互换穿着。
- **tag 顺序按官方 section**：`[质量/年代/meta/安全] → [人数] → [角色身份] → [作品] → [画师] → [general]`。人数用 `1girl` / `2girls` 这类计数形态写在靠前位置（最容易画错的一项，不许省）；同人角色名后面必须紧跟作品 tag，否则模型会认错人。
- **正面前缀一个字都不写**：质量词、年代词、画师串由渠道统一附加在 tag 串**最前**，规范里明说「那一串由用户自己填，你一个字都不要写，也不要换个说法重复」。
- **权重与词法按 Anima 的规矩**：`(tag:2)` 有效，但要给得比 SDXL 高（想要明显效果一般 1.5 以上、别超 2.5）；`::` 权重、`source#` / `target#` / `mutual#`、花括号权重一律不写；圆括号不当转义用（反斜杠只会原样进入语义）。
- **只写正面**：不产出 `negative` 键，也不写 `no xxx` / `without xxx`；不想要的一个字都别提，负面交给渠道设置里的 undesired 字段。
- **安全 tag 由 AI 判定、四档写死**：`safe` / `sensitive` / `nsfw` / `explicit`，按「这张图最终画出来是什么」判、不按正文氛围判，一张图只写一个档，拿不准取内容更重的一档（这条链路只写正面、没有负向手段，档位写低会让内容与档位互相打架，模型常见反应是加衣、遮挡或画畸形）。
- **长度目标 25~40 个短 tag**：Anima 是「提示词越详细越好」的模型，只有十来个词会得到平庸、简单的背景；但堆到四五十条、或写成整段长句，同样会互相稀释。
- **不写写实 / 渲染向词与 dataset 标签**（`photorealistic`、`3d render`、`ye-pop`、`deviantart` 等）：模型本体不做写实，这类词只会带来「动漫脸 + 油面 / 3D」的怪融合。元词只留一个白名单（`highres`、`absurdres`、`anime screenshot`、`official art`、`concept art`、`jpeg artifacts`），`monochrome`、`sketch` 这类会改写渲染方式的词归风格词，一律不写。

**思维链**保留了原来那份的三层结构（第一层 A~E 全局判断 / 第二层逐张槽位块 / 第三层落笔前自查）和「只写结论、不写推演」的纪律，改的是第二层的形状：

- **从「Base 块 + 每角色一块」变成「一张图一块」**：块内先写公共槽（安全档 / 人数 / 景别 / 核心互动 / 场景 / 环境光 / 元词 / size），再给每个可见角色各写一行角色行。归属不再由块隔离，而靠锚点词与 `X on Y` 绑定。
- 第一层 B 段因此多了一项活：**同一行里顺带定出这个角色的锚点词**，整楼同一角色必须沿用同一个 —— 第二层就靠它把服装、动作、手持物绑到正确的人身上。
- C 段服装时间线冻结的「视觉指纹」（版型 / 剪裁 + 主色 + 关键部件）就是第二层绑定时要照抄的那串词，不许写成 `school uniform`、`dress` 这类模型会自行重新设计的孤立词。
- 第三层多了一条**「绑定是否成立」**自查：多人同框时有没有一串裸服装词飘在两个人中间、有没有谁只有名字没有外貌、锚点词整楼是不是同一个。

两份都用 `{{#nl}}…{{/nl}}` / `{{^nl}}…{{/nl}}` 条件段兼顾「生成自然语言」开关的两侧：开着就让 nl 用英文补关系、相对位置、景别与光线；关掉就把这些压回 1–4 词的短 tag，规范与思维链同步翻面。顺手删掉了旧版那个从来没被展开的 `{{nlLang}}` 宏 —— 插件里没有展开它的代码，它会被原样漏给模型。

### 🎭 角色档案口径修正

与 Anima 无关，但一并带上了：

- **cos / 伪装造型的身份 tag 归 `fandom`**：角色本人判不出所属作品、但他穿着的可复用造型明确对应某个作品时，把**造型**的身份 tag 写进 fandom（`character name (copyright name)`），此后每楼逐字照抄；造型解除或更换的那一楼报 changes 更新，卸下造型且本人是原创就清空。
- **`outfit` 只记正文明确给出的部件**，并禁写暴露向词（`backless` / `cleavage` / `halterneck` / `see-through` / `lingerie`）与胸部尺寸词（`big breasts` / `large breasts` / `huge breasts` / `gigantic breasts` / `flat chest` / `busty`）—— 档案每楼照抄，写进去之后每张图都变成那样，正文没要求也叫不回来。
- **污染档案自动清理**：库中已有角色的 outfit / body / extra 命中上述词，或写着与身份 tag 原设明显不符的服装时，自动报 changes 清成干净值。
- **整段剧情维持同一造型时，`hair` / `eyes` 按造型外观（假发、美瞳）写**，留空会让模型每张自己随机；造型解除那一楼，`hair` / `eyes` / `fandom` / `outfit` 四格一起更新。
- 文案修正：「单楼最少图片数」说明改为「0 = 由 AI 自行判断，可能只出一张或不出图；填具体数字才是硬要求，不够会被判不合格并自动重试补足」；角色管理页 `fandom` / `outfit` 的占位符改写。

## 它能做什么

### 🖼️ 自动配图，精彩瞬间不错过
- **自动分析剧情**：每次 AI 回复后，柏宝绘会通读这段剧情，判断有没有值得画的瞬间——有就画，没有就安静跳过，绝不刷屏。
- **自动编写提示词**：英文正向 tag、画面描述、画幅方向、负面词全都自动写好，你几乎不用碰提示词。
- **一次多张**：想多要几张也可以，单次最多可规划多张图，按剧情节奏依次生成。
- **手动接管**：想指定某一楼出图？点楼层上的「生成 tag」按钮即可；写好的 tag 也会直接显示在图片卡片上，随时能看能改。

### 🎭 角色固定外貌库：外貌永不漂移
- **首次出场自动建档**：有名有姓的正式角色第一次出场，柏宝绘会自动记下他的发色、瞳色、体型等固定外貌，之后每一张图里的他都长一个样。
- **只报名字，不抄外貌**：AI 在提示词里只需写「@角色名」，插件会机械替换成档案里最新、最准确的外貌——彻底杜绝「这一楼金发、下一楼黑发」的漂移问题。
- **永久变化自动更新**：角色染发、剪发、留疤、长大……这些永久变化会被自动记进档案，且**按剧情位置生效**：变化之前的图片用旧外貌，变化之后用新外貌，时间线不错乱。
- **临时状态不混淆**：假发、湿身、包扎这类临时状态不会污染档案，但同一场景里会持续保持，直到剧情解除。
- **手动编辑与回滚**：档案随时可以手动修改、删除；每次 AI 的自动变更都有记录，一键回滚。
- **全局角色库**：玩家角色等「哪个聊天都用同一张脸」的角色，在角色管理页一键「提升为全局」——之后所有聊天自动生效，无需重复建档。全局角色是冻结档案：AI 永远不会修改它，完全由你手动维护；某个聊天想让他不一样，复制回本聊天即可覆盖。

### 🎨 出图渠道：ComfyUI 与 NovelAI
- **ComfyUI**：两种配置方式任选——**简易参数**模式直接选模型/LoRA、填步数等基础参数即可出图（内置 Checkpoint 系/Flux/Anima 模板，模型列表一键从 ComfyUI 拉取）；**自定义工作流**模式加载你自己的 API 工作流模板，占位符自动填充 tag、描述与尺寸，节点怎么连不用操心——**AI 会自动定位**该填哪个节点、哪些片段要保留，应用前还能预览改动。
- **多套工作流随时切换**：常用的工作流可以各存一套、各起名字，下拉一点就换。自然语言开关与横竖尺寸都跟着工作流走——二次元底模和 Flux 之间来回切，不用再逐项改设置。
- **固定横图 / 竖图**：每个渠道的尺寸旁边都有「画幅方向」：自动 / 竖屏 / 横屏。锁定后每张图都按这个方向出，AI 写提示词时也会按这个画幅去构图，不用再把横竖尺寸填成一样来凑（ComfyUI 每套工作流各设各的）。
- **NovelAI**：官方 v3 / v4 / v5 系列模型；支持 vibe 参考图（角色风、画风参考）；`.naiv4vibe` 文件与官方互通，导入导出都行。
- **Anima 提示词风格**：NAI 渠道里能把出口切成 Anima 口径（单串输出、自然语言为主、角色外貌写进主体、尺寸吸附网关三档），适合后端跑 Anima 的 NAI 兼容站——详见上面的「本版改了什么」。
- **自然语言单串风格**：同一个下拉的第三档，只出纯英文描述、不写任何 danbooru tag（首词为安全档），适合吃自然语言的出口。
- **NAI 多接入点随时切换**：官方站与各个第三方站可以各存一条、各起名字、各记各的 Key，下拉一点就换。换站只换出口——模型、采样器、尺寸、vibe、画师串这些参数全部照旧，不用重配一遍。官方那条是内置的，地址固定不用填。
- **NAI 自然语言可开可关**：NAI 4.5 的提示词有长度上限（画面与所有角色共用约 512 token），自然语言描述最占篇幅，超出的部分会被截掉、画面跟着走样。觉得 4.5 画得怪，可以在 NAI 渠道里关掉「生成自然语言」，让 AI 只写 tag 试试。
- **渠道灵活**：可以指派专门的副 API 渠道去跑生图，不占用主对话；不配置就跟随主 API。
- **画师串随时切换**：常用的画风/画师组合可以各存一套、各起名字，下拉一点就换，也可以选「不使用」。选中的画师串会拼在提示词最前面，整幅画的画风基调一次定好。
- **负面词、质量词智能默认**：每个模型都有官方推荐的质量词与负面词，点开就能看到实际生效的内容；想改就改，改完会标记「已自定义」，随时一键恢复默认。

### 📁 图片管理，随聊随存
- **内嵌楼层卡片**：生成好的图片直接嵌在对应楼层下方，与剧情一一对应。
- **显示大小可调**：电脑宽屏上嫌楼层里的图太大？设置页「楼层图片显示大小」有小 / 中 / 大 / 铺满四档。只改聊天里显示多大，不影响出图分辨率，图片文件原样不动。
- **点击放大、长按保存**：灯箱查看大图，长按图片即可保存到本地。
- **出图信息可回溯**：每张图随图记录完整提示词、画师串、vibe（含强度）、模型与采样参数；在灯箱或图库里点开就能看到当时到底怎么画的——喜欢的图再也不会忘记用的哪套配方。
- **重新生成与取消**：对某张图不满意，点一下重绘（同提示词再出一张）；觉得提示词写得不到位，打开铅笔（编辑提示词）弹窗，里面既可以自己改，也可以点「AI 重写提示词」让它重读剧情把这一张的提示词重写一遍再出图——只动这一张，同楼其它图片不受影响。重写期间可以放心关掉弹窗，生成不会中断，回头再打开还能接着看；想整楼重新选画面则用消息 ⋯ 菜单里的调色盘按钮。生成中也可以随时取消，不浪费额度。
- **智能队列**：多张图排队生成，并发数可调，不会把渠道挤爆。
- **可选 JPG 转存**：需要更小的文件体积时，可让 PNG 自动转存为 JPG。

### 🤝 与柏宝书无缝协作
- 柏宝绘读取柏宝书的角色状态与剧情记忆，让配图与「此刻的剧情」严丝合缝。
- 不想被某段内容打扰？**排除名单与柏宝书共享**——按角色、按世界书整本或按条目名排除，两端同步，一处设置两边生效。

### ⚙️ 想调多细都行
- **提示词全可编辑**：破限、生图规范、思维链……每一套都有内置默认，也可全部自定义。规范与思维链里还能用 `{{#nl}}…{{/nl}}` / `{{^nl}}…{{/nl}}` 写只在开 / 关「生成自然语言」时生效的段落，一份提示词两种模式都顺。
- **多主题界面**：自动跟随 SillyTavern 配色，手机、平板、电脑都顺手。
- **自动更新**：有新版时导航栏亮起小红点，设置页一键更新并自动刷新。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」里填入本仓库地址即可（本版已带编译好的 `dist/`，装完直接能用）：

```
https://github.com/Selena-xy/ST-BaiBai-Image
```

想装上游原版则填 `https://github.com/baibai-git/ST-BaiBai-Image`。

安装后进入「设置」页：先到「渠道」页配置出图渠道（本地 ComfyUI 或 NovelAI 账号），再确认「自动生成 tag」开关已打开，就可以开始自动配图了。设置会随 SillyTavern 保存在服务器，跨设备自动同步。

## 小贴士

- **开箱即用**：默认设置下，只要配好出图渠道，AI 每聊一段就会自动配图；不想自动出图、只想先写 tag 的，关掉「自动生成图片」开关即可。
- **角色外貌库是自动维护的**：你不用预先录入任何角色，第一次出场时插件会自动建档；想微调再进「角色管理」页动手。固定用的角色（比如玩家）可以「提升为全局」，换个聊天也不用重新建档。
- **ComfyUI 用户**：不想碰工作流 JSON 的话，用「简易参数」模式选个模型就能出图；有自己的工作流则用 AI 自动配置功能跑通一次，之后一直复用。有多套常用配置的，存成多套随时切换。
- **NovelAI 用户**：vibe 参考图不是必须的，但能让画风/角色更稳定；`.naiv4vibe` 文件与官方互通。
- **图片数据跟着聊天走**：删聊天即删对应图片数据，隐私可控。

## 给插件作者

柏宝绘开放了一套公开接口（`globalThis.STBaiBaiImage`），别的插件可以：

- **读角色库**：拿到柏宝绘已记录的角色和可直接出图的 tag；
- **调柏宝绘出图**：后端配置、并发闸门、限流退避、图库归档全都复用，**图显示在哪由你决定**——
  画在侧边栏、画在自己的弹窗里都行，生成的图不会进入任何聊天记录。
